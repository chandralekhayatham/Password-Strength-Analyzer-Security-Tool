Password vs. Passphrase

A long, unique passphrase made from randomly selected words can be easier to remember than a short, highly predictable password. Length and unpredictability matter more than simply checking four character categories.

Better assessment = Length + Unpredictability + Pattern resistance + Common-password checks + Context

Entropy shown by this project is an educational theoretical estimate. It assumes random character selection and should not be treated as a guaranteed measure of real-world guessing resistance.
